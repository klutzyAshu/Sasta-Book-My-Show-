> **A simple Java movie-ticket booking system — because booking a seat shouldn't require a PhD. 😎**

## 🚀 What is it?

**Movie ticket bookings** is a Java-based movie ticket booking application where users can:

* 🎥 Browse movies
* 🏢 Select theatres/shows
* 💺 View and select seats
* 🎟️ Book tickets
* 🗄️ Store booking data in MariaDB

The project is built to practice **Java, OOP, GUI development, JDBC, and database management**.

## 🛠️ Tech Stack

* ☕ Java
* 🖥️ Java Swing
* 🗄️ MariaDB
* 🔌 JDBC
* 🌱 Git & GitHub

## 📂 Project Structure

```text
src/
├── model/       # Movie, Theatre, Show, Booking...
├── dao/         # Database operations
├── ui/          # GUI screens
├── util/        # Utilities & helpers
└── db/          # Database connection
```

## ▶️ How to Run

1. Install **Java JDK**
2. Install and start **MariaDB**
3. Create the project database
4. Configure your database credentials
5. Add the required JDBC driver
6. Run the main Java class 🚀

## 🧠 Learning Goals

This project helps understand:

**Java → OOP → GUI → JDBC → SQL → Transactions → Real-world application development**

## 🐛 If something breaks...

Don't panic.

> **It's not a bug. It's a surprise feature.™**

Check your database connection, credentials, JDBC driver, and console errors first.
